02 Learning

Version control

Git keeps every version of a file, so two people can edit the same line without emailing final-final-v2.md around. A commit is a checkpoint I can return to.

Publishing

GitHub Pages turns a public repository into a website. Push the files, pick a branch, and the page appears at <username>.github.io.

Agent loops

An assistant is more than one model call. It reads a question, chooses a document to look up, checks the result, and only then answers — or asks for something else.
